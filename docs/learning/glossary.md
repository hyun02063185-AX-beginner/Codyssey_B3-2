# 용어집

| 용어 | 쉬운 뜻 |
|---|---|
| Python | 이 CLI를 작성한 프로그래밍 언어 |
| CLI | 터미널 명령으로 쓰는 프로그램 |
| 모듈 | 다른 Python 파일에서 `import`할 수 있는 코드 파일 |
| 함수 | `def`로 정의한 재사용 작업 |
| 인수 | 명령이나 함수에 전달하는 값 |
| 예외 | 실행 중 오류를 알려 주는 Python 신호 |
| Git | 로컬 파일 변경 이력을 관리하는 도구 |
| GitHub | Git 저장소 공유·협업 서비스 |
| 저장소 | Git이 이력을 관리하는 폴더 |
| 작업 트리 | 현재 편집 중인 파일 상태 |
| 스테이징 | 다음 커밋에 넣을 변경을 고르는 단계 |
| diff | 두 파일 상태 사이의 차이 |
| 브랜치 | Git 이력의 작업 줄기 |
| commit | 선택한 변경을 로컬 이력으로 기록 |
| push | 로컬 커밋을 원격 저장소에 전송 |
| PR | 브랜치 변경을 검토·병합해 달라는 요청 |
| API | 프로그램 사이 기능 호출 약속 |
| REST API | URL·HTTP를 사용해 데이터를 주고받는 API 형태 |
| HTTP/HTTPS | 웹 요청·응답 규칙 / 암호화된 연결 |
| URL | API 서버의 주소 |
| JSON | 키와 값으로 구성된 데이터 텍스트 형식 |
| API 키 | 서비스 접근 권한을 증명하는 비밀 문자열 |
| 환경변수 | 운영체제가 프로그램에 전달하는 설정값 |
| 프롬프트 | AI에게 주는 작업 지시 |
| 컨텍스트 | AI가 답변에 참고하는 Git 변경 정보 |
| temperature | 모델 출력 무작위성 조절 요청값 |
| 토큰 | 모델이 텍스트를 처리하는 단위 |
| 모의 API | 테스트에서 실제 서버 대신 쓰는 준비된 응답 |
| 마스킹 | 민감한 문자열을 가림말로 바꾸는 일 |
