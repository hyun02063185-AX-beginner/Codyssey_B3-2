# B3-2 요구사항 재대조

2026-10-20 기준. 대조 원문은 사용자가 제공한 **「Codyssey B3-2 — 자율 개발·QA·학습자료 제작 통합 지시서」**다. 별도의 코디세이 공식 평가 원문은 저장소와 공개 자료에서 확보되지 않았다. 따라서 아래 표는 제공된 지시서 전체와 구현·증거를 대조한 결과이며, 공식 원문과의 일치를 확정하는 자료는 아니다.

| 요구사항 묶음 | 상태 | 구현·검증 근거 | 남은 범위 |
|---|---|---|---|
| Python 3.10+ CLI, `commit`/`pr`, `--help`, README·`.gitignore` | 충족 | `main.py`, README, Stage 0 실행 기록 | Python 3.10 자체에서 실행한 테스트는 없음(Windows 3.14.6 검증) |
| Git 저장소 판별, 브랜치·파일·status·unstaged/staged diff·변경 없음 | 충족 | `git_collector.py`, `test_git_collector.py` 및 `test_cli.py` | 미추적 파일은 의도대로 이름만 전송 |
| 안전한 Git subprocess | 충족 | `_git()`이 인수 목록으로 `subprocess.run()` 사용 | 없음 |
| API 키 환경변수, REST·HTTP·JSON, 인증 | 충족(사용자 실제 실행) | `ai_client.py`, 모의 테스트, 사용자 제공 코디세이 API 정상 응답 2회 | 실제 키 값·원본 HTTP 기록은 저장하지 않음 |
| 모델·temperature·max_tokens 설정 | 부분 충족 | 모델 `gpt-5-mini` 실제 성공; 선택 파라미터는 요청 JSON 단위 테스트 | 코디세이 모델의 선택 파라미터 지원 미확인 |
| 인증 실패·네트워크 오류·잘못된 JSON·요청 횟수 | 충족(모의) | `test_ai_client.py`, `test_cli.py`; 정상 실제 실행은 명령당 1회 | 실제 서비스 장애 시나리오는 호출하지 않음 |
| 커밋 요약·제목/선택 본문·길이·형식·출력 | 충족 | `prompts.py`, `validators.py`; 사용자 제공 실제 제목과 본문 정확성 확인 | AI 의미 정확성은 변경마다 사람 검토 필요 |
| PR 제목 80자, Why/What/How to Test 및 불릿 | 충족 | `validators.py`; 사용자 제공 실제 PR 제목·세 섹션 확인 | 실제 PR 본문 전문은 제공되지 않음 |
| 테스트 실행 사실 날조 방지 | 부분 충족 | How to Test를 실행 권장 명령으로 교체, Why/What의 대표적 성공 주장 차단 | 모든 자연어 허위 주장을 기계적으로 검출할 수 없음 |
| 기본 안전 모드, 민감정보 마스킹·전송 제한 | 부분 충족 | `security.py`, 모의 마스킹·차단·`--unsafe` 전후 테스트 | 알려지지 않은 비밀 형식 및 실제 송신 데이터 완전성은 보장할 수 없음 |
| 정상·오류·보안 통합 QA | 충족(검증 범위 내) | 전체 `unittest` 14개 통과, 실패 0개; 사용자 제공 실제 정상 응답 2회 | 실제 잘못된 키·네트워크 장애는 모의 검증만 수행 |
| Windows·macOS 실행법과 CLI 예시 | 문서 충족 | README 및 학습자료 | macOS 실기기 실행은 미검증 |
| Stage 0~7 기록, 학습자료 목차·8개 장·용어집 | 충족 | `reports/stages/`, `docs/learning/`; 장별 목표·개념·흐름·소스·실습·결과·오류·문제 3개 | 별도 공식 원문과의 교육 내용 대조 미완료 |
| 의미 있는 Git 커밋, 원격 `main` 반영 | 충족 | `git log`, `git push`, 원격 SHA 일치 확인 | 후속 문서 갱신 push 후 SHA 재확인 |
| 실제 AI 생성 메시지를 Git 커밋에 적용 | 미확인 | 실제 제목은 사용자 제공; 사용 커밋은 보고되지 않음 | 적용 사례가 필요하면 별도 확인 |
| 자동 PR 등록·승인·병합 금지 | 충족 | CLI는 초안만 출력 | 없음 |

**결론:** 제공된 지시서의 핵심 CLI와 정상 실제 API 응답은 확인됐다. 공식 평가 원문 대조, 선택 파라미터 지원, 안전 모드의 완전성, 실제 AI 제목의 커밋 적용은 별도 미검증 항목이다. 결과 출처와 상세 내용은 [QA 보고서](QA.md)에 기록했다.
