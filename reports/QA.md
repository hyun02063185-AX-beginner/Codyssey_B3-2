# B3-2 최종 QA 보고서

검증일: 2026-10-20 (Asia/Seoul). 대조 기준: 사용자가 제공한 B3-2 통합 지시서. 별도 **공식 B3-2 평가 원문**은 저장소와 공개 자료에서 확인되지 않아 원문과의 최종 대조는 미완료다. 아래에서 사용자 제공 실제 API 실행 결과와 Codex 직접 테스트를 구분한다.

## 실행 환경과 결과

- 로컬 저장소: `main`, 초기에는 커밋 없음. GitHub 원격 주소 `https://github.com/hyun02063185-AX-beginner/Codyssey_B3-2`.
- Windows, Python 3.14.6, Git 2.54.0.
- Codex 직접 테스트: `python -m unittest discover -s tests -v` → **14개 통과, 0개 실패**. `python -m compileall -q main.py ai_gitgen tests` 통과. 이 테스트에는 실제 유료 API 호출이 없다.
- 사용자 제공 실제 실행 결과(2026-10-20, Windows PowerShell): `https://copa.codyssey.kr/v1/chat/completions`, 모델 `gpt-5-mini`, `CODYSSEY_API_KEY` 환경변수로 `python main.py commit`과 `python main.py pr`이 각각 성공했다. API 요청은 명령별 1회, 합계 **2회**다. Codex는 이 호출을 재실행하지 않았다. 원본 터미널 출력 전문은 제공되지 않아 이 기록은 사용자의 실행 결과 요약에 근거한다.
- 실제 응답 품질: 커밋 제목 `학습 문서에 실습 메모 추가: AI 생성 커밋 메시지 검토 필요`(35자). 사용자는 본문이 `docs/learning/02-python-ai-api.md`의 실습 메모 추가를 정확히 설명했다고 확인했다. PR 제목 `docs(learning): AI 생성 커밋 메시지 검토 안내 추가`(37자). 사용자는 Why에 목적, What에 실제 파일·문구, How to Test에 실행 권장 명령이 있음을 확인했다. 제공되지 않은 본문 문장은 재구성하지 않았다.
- 모의 API: JSON 요청·응답과 CLI 통합 흐름 검증. 정상 `commit`/`pr` 실행마다 1회 요청, 변경 없음·키 없음은 0회. 자체 저장소의 미커밋 README·프롬프트·학습자료 변경으로 만든 문맥을 모의 API에 보냈고 `commit`/`pr` 형식을 각각 1회 확인했다. 이것은 실제 AI 품질 검증이 아니다. 모의 커밋 제목 `학습자료와 한국어 초안 지시 추가`를 문서 커밋에 활용했다.

## 오류·보안 검증

저장소가 아닌 디렉터리, 변경 없음, 미추적/스테이징/추가 편집, 키 누락, 모의 401·네트워크 실패·잘못된 응답, 제목 길이, PR 필수 불릿, 이메일·토큰 마스킹, `.env` 경로, 불완전한 개인키 블록, 안전 모드 해제 차이를 테스트했다. 자체 코드 변경을 모의 검증할 때 테스트 파일의 개인키 시작 표지가 안전 모드에 걸려 전송이 중단됐다. 이 동작을 성공적인 차단으로 기록하고, 테스트 파일을 커밋한 뒤 남은 실제 변경분에 대해 모의 생성 검증을 다시 수행했다.

## 남은 미검증 항목

1. B3-2 공식 평가 원문과의 직접 대조. 현재 대조는 사용자가 제공한 통합 지시서 기준이다.
2. 코디세이 공급자에서 `temperature`와 `max_tokens`를 지원하는지 여부. 필요할 때 공식 문서로 확인한다. 이를 검증하려고 유료 요청을 추가하지 않는다.
3. 안전 모드가 실제 전송 문맥의 모든 민감정보를 가렸는지 여부. 자동 패턴 검사에는 한계가 있으므로 외부 전송 전 diff의 사람 검토가 계속 필요하다.
4. 실제 AI가 생성한 제목을 Git 커밋에 사용한 기록. 실제 초안은 확인됐지만 적용 커밋은 보고되지 않았다.

통합 지시서의 핵심 실행 경로와 실제 API 정상 응답은 확인됐으며, 별도 공식 평가 원문이 없으므로 **공식 요구사항 전체 완료 판정은 보류**한다.
